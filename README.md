## 住宿对应的行程

9/28独山子经独库北段、乔尔玛进唐布拉百里画廊，住古道民宿；9/29早餐后返乔尔玛转那拉提。两天道路分别约181、149公里。古道民宿最后约1.88公里路段通行尚待店家确认，地图使用琥珀色虚线；本店8/20、8/27发布的评价提到古道关闭但仍描述入住，说明闭园不必然阻断住宿。道路名称不等于管控边界，9/28实际车辆入口仍须店家确认。独库关闭时须重排路线并核对已订住宿处理，不自动改酒店。

9/30游那拉提后，16:30左右从游客中心开约67公里到新源汉庭。10/1退房、库尔德宁往返约156公里，目标16:00回外部停车场、18:00住新源维也纳。10/2由新源经特克斯到昭苏约224公里。10/3先退麗枫，游夏塔后住桔子，两晚不同店。

10/4经G577到清水河汉庭约251公里，不默认走伊昭S237。10/5清水河进赛湖84.4公里，顺时针环湖89.9公里，再到精河星程136.8公里；湖内约6小时包含驾驶、观景和午餐，争取17:00离东门，19:00—19:30到酒店。果子沟默认车窗远眺，不在高速或大桥临停。

10/6从精河星程10:00出发，直达143团花园镇你好酒店约260.5公里；选独山子大峡谷则约326.4公里，另留1.5小时观景，傍晚到店。两种节奏可在页面切换。花园镇不是石河子市区；百里丹霞仍为未选备选，未计入日程或预算。

10/7约09:00从花园镇出发，赴机场约153公里，纯驾驶预留2.25—3小时，另留补油及验车时间，目标12:30左右到一嗨站点、14:00前办结。当晚住全季阳光恒昌，用户已确认10/8有05:00班车，酒店称约10分钟到机场，按05:10到达规划。距06:45起飞95分钟，目标05:40前完成托运、06:05前到登机口；具体航司截载时间待核，班车可用不是误机风险保证。

主线道路模型合计约2139.4公里，逐日取整规划2170公里；峡谷版增加约65.9公里。预算按2400公里预留。那拉提/库尔德宁景内车辆里程另计，机场还车后的接驳与次日送机独立显示且不计租车里程。道路模型非实时路况，酒店坐标仅作为附近道路参考，停车入口未实地核验。

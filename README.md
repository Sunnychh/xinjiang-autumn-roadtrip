# 伊犁秋日自驾路书

2026 年 9 月 27 日至 10 月 7 日，2 人、11 天 10 晚的自驾规划。

在线查看：https://sunnychh.github.io/xinjiang-autumn-roadtrip/

包含逐日时间线、真实道路路线与方向箭头、住宿与餐厅参考、景点照片、费用口径及可调整预算。图片和信息出处均在页面卡片中提供。规划不是预订，票价、路况与营业以出行时确认信息为准。

## 地图使用

请通过上面的 HTTPS 网页访问完整在线地图。直接打开下载的 HTML 文件时，只显示内置的行程区域地理简图，并提供网页版入口。

完整地图使用 Leaflet 与 OpenStreetMap 标准瓦片。请求保留真实网页来源及浏览器默认身份，遵循 HTTP 缓存，不提供离线下载或瓦片批量预取。请求被拒绝时，不显示服务端错误图片，保留内置简图、路线与地点。

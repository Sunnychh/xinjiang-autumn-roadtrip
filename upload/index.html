第一次使用：怎样创建令牌？
  1. 使用照片仓库所有者 Sunnychh 的账号，打开 GitHub 的 Fine-grained token 页面 ↗，设置名称和有效期。
  2. Resource owner 选择 Sunnychh；Repository access 选择 Only select repositories，仅勾选 xinjiang-trip-memories。
  3. Repository permissions 中，将 Contents 设为 Read and write，Metadata 保持自动提供的读取权限。
  4. 生成后复制令牌，粘贴到上方。不要把令牌写在照片附言里。
